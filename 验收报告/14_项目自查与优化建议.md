## 二、本次自查发现的确有问题（需决策）

### 🔴 F-1【P1】长期记忆（Qdrant 向量层）实为死代码
- **证据**：`config.py:91` `embedding_model` 默认 `""`；`.env` 未设 → health `embedding:not_configured`。`router.py:405-415` 与 `:445-455` 的向量检索整段因 `client.embed()` 返回 `None` 被跳过；`manager.py:72` `_ensure_long()` 拿不到 embedding 维度直接降级关闭。
- **后果**：报告担心的"向量检索→增强回答"链路**当前未真正闭环**。AI 只会用到短期记忆(Redis) + 个人事实库(PG)，**不会越聊越懂你**。
- **可选优化（二选一）**：
  1. 启用：在 `.env` 配 `EMBEDDING_MODEL`（OpenAI 兼容 `/embeddings`，如 bge-m3 代理）+ `EMBEDDING_API_KEY` + `EMBEDDING_API_BASE`，让长期记忆真正生效（需 Qdrant 已起）。
  2. 若决定不启用：把检索段标注为 optional 并从"已实现功能"表述里剔除，避免构成"假功能"。

### 🔴 F-2【P1】长期记忆检索忽略 user_id（隔离守卫形同虚设）
- **证据**：`router.py:410` 与 `:450` 均 `search_similar(vec, limit=3, user_id=None)`；而写入用 `user_id="me"`（`router.py:528`）。`vector_memory.py:60` 的 `user_id` 过滤分支**永远不触发**。
- **后果**：当前单用户无碍；但这是报告 M-002 隐患的**真实残留**——一旦多用户，检索会跨用户泄露长期经验。
- **优化**：检索改为传真实 `user_id`（与写入一致），让隔离守卫真正生效。

### 🟠 F-3【P1/设计】技能即任意代码执行，无权限清单
- **证据**：`api_skill.write_skill_package` + 端点 `/api/skills/package`(main.py:1045) 把任意 `handler.py` 写入并热加载执行；仅要求含 `class SkillHandler` 且需登录。报告 S-001 建议的"Skill Permission Manifest"至今未实现。
- **评估**：单机单用户 + Bearer 令牌门控下**可接受**，但属设计性风险——任何拿到令牌的人可在宿主机执行任意 Python。
- **可选优化（按需）**：① handler 静态黑名单（禁 `subprocess`/`os.system`/`eval`/`exec`）；② 该端点限定仅本地/Admin；③ UI 明确"仅可信代码"警示（docstring 已有，可补到前端）。

### 🟠 F-4【P2】部分 AI 端点未做限流/成本保护
- **证据**：`ai_rate_limiter` 仅接在 chat/chat-stream；而 `/api/models/fetch`、`/api/models/speedtest`、`/api/ai/nvidia-probe`(main.py:1296) 会触发真实外部模型调用（拉取/测速/探测全量模型），**无限频**，存在被滥刷产生第三方费用的风险。
- **优化**：对测速/探测/拉取类端点加限流或限定 Admin。

### 🟡 F-5【P1】前端工程化不足（F-001 确认）
- **证据**：`frontend/src` 仅有 `components/`，**无 router/views/store**（Glob 实锤）。Chat/Dashboard/Config/ModelConfig/SkillConfig/Backup 等组件齐全、功能可跑，但全部平铺。
- **后果**：报告指出的"多页面扩展难、权限页面隔离难、业务逻辑易进组件"属实。
- **优化**：引入 Vue Router + Pinia + views 分层（工作量较大，建议作为**后续专项**，非本次必改）。

### 🟢 F-6【P2】缺少 RBAC（SEC-004）
- 仅单因子 OTP Bearer 鉴权，无角色区分。个人单机系统可接受，记录为已知项。

## 三、已确认安全良好的项（正面结论，免改）

- **公开端点收敛**：仅 `/api/health`、`/api/auth/{setup,login,check}`、`/api/connector/webhook` 免鉴权。
- **Webhook 安全**：`/api/connector/webhook` 要求 `CONNECTOR_WEBHOOK_TOKEN`，HMAC `compare_digest` 常量比较（抗时序），未配置则 503 禁用；`handle_inbound`(connector.py:32) 仅路由 todo/memory/chat/raw → 落库/建待办，**无命令执行**。
- **CORS**：显式来源列表（非 `*`），`allow_credentials=True` 但来源受限。
- **安全响应头**：CSP / `X-Content-Type-Options:nosniff` / `Referrer-Policy:no-referrer` 已加（`main.py:222`）。
- **登录防暴破**：`_login_fail` 内存限流（main.py:137）。
- **密钥管理**：全部环境变量/运行时存储，无硬编码。
