# 第一部分：验收问题整改（P1/P2）

## A1【P1-2】备份打包排除密钥文件（止血，10 分钟）

**位置**：`app/backup.py` data 目录打包函数
**问题**：otp_secret / session_secret / settings_runtime.json 明文密钥随备份外泄
**改法**：打包 data 目录时排除敏感文件

```python
# backup.py 打包 data 目录处，加入排除清单
EXCLUDE_FILES = {"otp_secret", "session_secret", "settings_runtime.json"}

# tar 添加文件时过滤（伪代码位置：data 目录遍历处）
if item.name in EXCLUDE_FILES:
    continue
```

**验收标准**：手动跑一次备份，解包确认无这三个文件。

## A2【P2-2】PG 端口收回本地（5 分钟）

**位置**：`docker-compose.yml` postgres 服务
**改法**：

```yaml
    ports:
      - "127.0.0.1:5433:5432"   # 原为 "5433:5432"（0.0.0.0 全网段可连）
```

执行：`docker compose up -d postgres`（改端口映射须重建该容器）。
**验收标准**：`netstat -an | grep 5433` 显示 127.0.0.1:5433；LifeOS 后端连接不受影响（宿主经 127.0.0.1 访问）。

## A3【P2-3】删除硬编码兜底密码

**位置**：`docker-compose.yml` 与 `app/backup.py` L30
**改法**：

```python
# backup.py L30 附近
PG_PASSWORD = os.environ.get("LIFEOS_DB_PW")  # 删掉 or "lifeos_pg_2026" 兜底
if not PG_PASSWORD:
    raise RuntimeError("LIFEOS_DB_PW 未配置，备份无法执行")
```

**验收标准**：`.env` 有 LIFEOS_DB_PW；删掉它后 compose 启动报明确错误。

## A4【P2-1】SFTP 备份校验主机密钥

**位置**：`app/backup.py` SFTP 传输函数
**改法**：

```python
# 原：client.set_missing_host_key_policy(paramiko.AutoAddPolicy())
# 改为：首次连接后主钥落盘 known_hosts，之后强校验
kh = Path(data_dir) / "known_hosts"
client = paramiko.SSHClient()
if kh.exists():
    client.load_host_keys(str(kh))
    client.set_missing_host_key_policy(paramiko.RejectPolicy())
else:
    client.set_missing_host_key_policy(paramiko.AutoAddPolicy())  # 仅首次
client.connect(host, port=port, username=username, password=password, timeout=30)
if not kh.exists():
    client.save_host_keys(str(kh))  # 首次连接后固化
```

**验收标准**：known_hosts 生成后，篡改目标主机密钥时备份报 SSH 异常而非静默传输。

## A5【P2-4】TOTP 防重放

**位置**：`app/auth.py` login 校验处
**改法**：30 秒窗口内同一码只能用一次

```python
# auth.py 顶部
_used_otp: dict[str, float] = {}  # code -> 过期时间戳

# login() 校验通过后、签发 token 前
now = time.time()
_used_otp = {c: t for c, t in _used_otp.items() if t > now}  # 顺手清过期
if code in _used_otp:
    return None  # 重放拒绝
_used_otp[code] = now + 60
```

**验收标准**：同一动态码 1 分钟内第二次登录返回 401。

# 第二部分：新需求「主动提醒引擎」

## B1 目标

> 阿勇随口一句话 → Agent 识别出"未来要做的事/要回访的事" → 落库 → 到点飞书主动推送。
> 覆盖：到期提醒（还款/讨债）、定期回访（头痛跟进）、任意"X 天后提醒我"。

## B2 架构（全部复用现有零件）

```
你说一句话
   ↓
agent/router.py 意图分类（新增 reminder 意图分支）
   ↓
ai/client.chat_json 提取 {事项, 到期日, 提前几天, 是否回访}
   ↓
db_store.py 新增 Reminder 模型 → PG reminders 表
   ↓
app/reminder.py 调度线程（抄 backup.py 模式，每 60 秒扫一次）
   ↓ 到点
feishu.py push_to_users(settings.feishu_admin_users, 文本)
```

**前置条件**：`settings.feishu_admin_users` 当前为空（health 实测 admin_users:[]），需先配好阿勇的飞书 open_id，否则推送静默丢弃（push_to_users 已做降级，不会报错）。

## B3 数据表（`app/skills/db_store.py` 追加）

```python
class Reminder(Base):
    __tablename__ = "reminders"

    id: Mapped[str] = mapped_column(String(12), primary_key=True)
    user_id: Mapped[str] = mapped_column(String(64), index=True)
    created_at: Mapped[int] = mapped_column(BigInteger)
    title: Mapped[str] = mapped_column(String(256))        # 事项：浦发信用卡还款
    detail: Mapped[str] = mapped_column(Text, default="")  # 细节：欠2万
    due_at: Mapped[int] = mapped_column(BigInteger)        # 到期时间 epoch
    advance_days: Mapped[int] = mapped_column(Integer, default=1)   # 提前几天提醒
    repeat_interval_days: Mapped[int | None] = mapped_column(Integer, nullable=True)  # 回访间隔，空=一次性
    repeat_remaining: Mapped[int] = mapped_column(Integer, default=0) # 剩余回访次数
    status: Mapped[str] = mapped_column(String(16), default="pending")  # pending/sent/done/cancelled
    last_sent_at: Mapped[int | None] = mapped_column(BigInteger, nullable=True)
    source: Mapped[str] = mapped_column(String(16), default="chat")  # chat/manual
```

无需 Alembic——`init_db()` 的 `create_all` 启动时自动建表。

## B4 调度器（新文件 `app/reminder.py`）

```python
"""主动提醒引擎：定时扫 reminders 表，到点走飞书推送。
模式照抄 backup.py 的 start_backup_scheduler。"""
import threading
import time
import logging
from app.config import settings

logger = logging.getLogger("lifeos.reminder")
_stop: threading.Event | None = None
_thread: threading.Thread | None = None
SCAN_SECONDS = 60


def _loop() -> None:
    from app.skills.db_store import due_reminders, mark_reminder_sent, reschedule_reminder
    from app.feishu import feishu_bot  # 与 main.py 中同一实例
    while not _stop.is_set():
        try:
            for r in due_reminders(advance_window=True):
                text = f"⏰ LifeOS 提醒：{r.title}\n{r.detail}".strip()
                sent = feishu_bot.push_to_users(settings.feishu_admin_users, text)
                if sent > 0:
                    if r.repeat_interval_days and r.repeat_remaining > 0:
                        reschedule_reminder(r.id)   # 回访类：顺延下一周期
                    else:
                        mark_reminder_sent(r.id)    # 一次性：status=sent
                    logger.info("提醒已推送: %s", r.title)
        except Exception as e:
            logger.error("提醒扫描异常: %s", e)   # 兜底，绝不卡死线程
        if _stop.wait(SCAN_SECONDS):
            break


def start_reminder_scheduler() -> None:
    global _thread, _stop
    if _thread and _thread.is_alive():
        return
    _stop = threading.Event()
    _thread = threading.Thread(target=_loop, daemon=True)
    _thread.start()
    logger.info("提醒调度已启动（每 %ds 扫描）", SCAN_SECONDS)
```

## B5 Agent 意图接入（`app/agent/router.py`）

```python
REMINDER_PROMPT = """从用户的话里提取提醒事项。只输出 JSON：
{"is_reminder": true/false, "title": "事项", "detail": "细节含金额",
 "due_date": "YYYY-MM-DD", "advance_days": 提前几天提醒,
```
