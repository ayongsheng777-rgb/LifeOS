## 二、多模型管理

- 配置双通道：env 兜底 + settings_runtime.json 热改，接口读取已脱敏 ✅

## 三、Agent 架构

- 管线：重置/事实写入指令 → 关键词快路 → AI JSON 意图分类（失败降级）→ 技能执行/多步编排（LLM 生成 steps，上限 4 步）→ 默认对话（注入事实库 + Qdrant 检索）
- 无 function-calling 协议，自研 JSON 计划 + 技能名匹配——对个人系统够用，对复杂工具生态是上限
- 权限控制：**无技能级权限**，所有技能对已认证用户全部可执行（单用户合理，产品化需补）
