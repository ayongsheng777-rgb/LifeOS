# 01 项目分析报告 — LifeOS V2.0

> 验收日期：2026-08-18 ｜ 验收依据：《AI软件验收智能体规范 V1.0》

## 项目识别

| 项目 | 内容 |
|---|---|
| 项目名称 | LifeOS V2.0（个人生活操作系统 / AI 数字伴侣） |
| 项目类型 | Web 应用（前后端分离，后端同源托管 SPA）+ AI Agent 系统 |
| 业务目标 | 个人知识/记忆/待办/记账/资讯统一管理，AI 对话与技能执行，数据自动备份 |
| 用户群体 | 单用户（阿勇本人），个人自用系统 |
| 部署环境 | Windows 宿主（后端宿主 venv uvicorn 直跑 :7208）+ Docker（PG/Redis/Qdrant）；Cloudflare Tunnel 对外 |
| 运行方式 | 后端 `uvicorn app.main:app --port 7208`（宿主托管 venv）；数据层 3 容器 |

## 技术栈

| 层 | 技术 |
|---|---|
| 后端 | Python + FastAPI 0.115.6 + uvicorn 0.34.0（强锁版本） |
| ORM | SQLAlchemy 2.0.36（asyncio）+ asyncpg |
| 前端 | Vue 3.4.21 + Vite 5.2.8，无路由库（tab 条件渲染）、无状态管理、无 UI 库（手写 CSS） |
| 数据库 | PostgreSQL 16（主数据）+ Redis 7（短期记忆）+ Qdrant v1.6.1（向量长期记忆） |
| AI | OpenAI 兼容客户端（httpx），多模型注册表 + 故障转移，当前激活 z-ai/glm-5.2 |
| 集成 | 飞书 Bot（WS 长连接 + 扫码设备授权流）、TOTP（RFC 6238 自实现） |

## 代码规模

- 后端：`app/` 约 12 个模块，main.py 1318 行（全部 60+ 端点集中在单文件）
- 前端：`src/` 10 个组件（Dashboard/Chat/Todo/Expense/News/Feishu/ModelConfig/Backup/Config/Login + SkillConfig）
- 构建产物：dist 约 237KB（单 bundle，未分包）

## 数据库类型

- PostgreSQL：todos / expenses / personal_facts / ai_usage 共 4 表（`create_all` 建表，无 Alembic 迁移）
- Redis：短期记忆 list + 杂项缓存
- Qdrant：`lifeos_experience` 集合（1024 维 bge-m3）

## 依赖服务

- 必需：PostgreSQL、Redis、Qdrant（Docker 三容器，均已运行 9h+）
- 可选：AI 模型 API（外网）、飞书开放平台、备份目标（本地/SMB/SFTP/FTP/WebDAV）

## 项目定位结论

这是一个**单用户、自托管、AI 原生**的个人管理系统。架构取舍（单用户 `DEFAULT_USER="me"`、进程内存态会话）与其定位匹配，不应以多租户 SaaS 标准苛求；但安全防线高度集中于 TOTP 单因子，是验收关注的重点。
