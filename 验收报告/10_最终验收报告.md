## 三、核心证据（实测）

- **服务在线**：127.0.0.1:7208 健康检查 200/6ms；PG/Redis/Qdrant 三容器稳定运行 9h+
- **业务闭环全通**：待办（建/查/完成/删除）、记账（建/查/月汇总/删/负数拒绝）、记忆四层、Agent 对话、模型管理、备份面板、AI 用量——18/18 通过，数据一致性逐项核验
- **安全防线实测有效**：无 token/伪造/篡改 token 全部 401；SQL 注入无 500；XSS 有 DOMPurify 消毒；错误 OTP 401 + IP 限流 429
- **性能达标**：常规 API <40ms；20 并发零错误 164ms 完成
- **日志干净**：backend.log 0 错误；uvicorn 访问日志全部正常

## 四、必须直面的两个问题（P1）

1. **技能热加载 = 设计内 RCE**：`/api/skills/package` 把提交的 Python 代码直接写盘加载，零沙箱。安全性完全系于 TOTP 单因子。
2. **密钥明文落盘**：settings_runtime.json 明文存 AI key/备份密码，data 目录即"全钥匙串"。

这两个问题在"单用户+自用+Tunnel 保护"前提下风险可控，但必须在文档中明示，且**任何产品化/多用户化动作之前必须先解决**。
